# Аудит креативов — серверная часть (Google Apps Script)

Страница `audit.html` берёт данные из того же Apps Script, что и `report.html`.
Код скрипта хранится в Apps Script; здесь лежит копия `audit.gs` для истории изменений.

## Подключение (один раз)

1. Apps Script → Файлы → «+» → Скрипт → назовите `audit` → вставьте `audit.gs` целиком.
2. В `Code.gs`, в функции `route_()`, перед строкой `if(action === 'setsites'){` добавьте:

   ```js
   if(action === 'audit')     return out_(iaAudit_(p.from, p.to, (p.force==='1'||p.force===1)), cb);
   if(action === 'gettags')   return out_({tags: iaGetTags_()}, cb);
   if(action === 'settag'){ iaSetTag_(p.k, p.t||''); return out_({ok:true}, cb); }
   ```

3. Deploy → Manage deployments → карандаш → Version: **New version** → Deploy.
   Адрес развёртывания не меняется, поэтому `API_URL` в страницах трогать не нужно.
4. Запустите `testAudit` (последние 2 недели) — в журнале появятся креативы, hook rate и число лидов.
5. Запустите `installAuditTrigger` — каждые 6 часов скрипт докачивает лиды amoCRM по месяцам,
   чтобы запрос за год открывался быстро.

Новых свойств скрипта не нужно: используются `FB_TOKEN`, `FB_ACCOUNT`, `AMO_SUBDOMAIN`, `AMO_TOKEN`, `PAYMENTS_SHEET_ID`.
У токена Meta должно быть право `ads_read`.

## Как устроено

- `?action=audit&from&to` — объявления Meta за период одной строкой на объявление
  (расход, показы, клики, 3-секундные просмотры `video_view`, ThruPlay, досмотры 25–100%,
  среднее время), превью и видео креатива; лиды amoCRM с ответом квиза «как давно занимаешься спортом»;
  оплаты из таблицы. Всё сводится по креативу = название объявления (utm_content).
- Лиды amoCRM хранятся на Диске по месяцам (`aud_leads_YYYY-MM.json` в папке «Invictus · отчёт (служебное)»):
  свежие месяцы обновляются раз в 6 часов, старые — раз в 7 дней. Если за один запрос всё не успело
  скачаться, страница пишет, какие месяцы ещё докачиваются.
- Разметка креативов (приём хука, формат, герой, смысл, сегмент) хранится в `ad_tags.json` на Диске
  и общая для всех. В скрипт встроена стартовая разметка 59 роликов, просмотренных в ноябре 2026.
- Правила квала и продажи (`audClass_`) и направления (`audDir_`) повторяют `report.html`.
  Если меняете их там — поменяйте и здесь.
