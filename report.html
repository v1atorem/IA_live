Экономика

По рекламному направлению

Направление — по utm_medium. Расход кампании за период делится между направлениями пропорционально её лидам. План по лидам — в разделе «План» ниже, по продуктам и городам.

Города

Направление × город: экономика

Факт-город лида из amoCRM. Адсеты таргетированы на пару городов, поэтому расход кампании делится по городам пропорционально лидам: CPL внутри кампании почти одинаковый, сравнивайте по CPQL, CAC и ROMI.

Динамика

Динамика по продукту и городу

Квалы, продажи и выручка считаются по дате создания лида (когорта дня/недели). Расход кампании делится на сегмент пропорционально её лидам за выбранный период; лиды без рекламы идут с нулевым расходом.

Утечка

Что рекламировали и что в итоге продали

Строка — продукт, который реально интересовал лида (поле «Курс», форма, страница сайта), и его город, как в планах. Колонка — какая реклама привела лида. Подсвечены ячейки, где реклама и продукт совпали. В ячейке — число и доля от строки.

Продажи: реклама → проданный продукт

Сквозная аналитика

Креативы: кампания → группа → объявление

Расход, показы и клики — из Facebook по каждому объявлению. Лиды привязаны к объявлению по метке utm_content (ID или название объявления) внутри кампании utm_medium. Продажи — из amoCRM, оплаты — из таблицы оплат по ID сделки.

Конверсия сайтов

Сайт определяется по полю referer у лида. Каждому сайту назначьте кампании, группы или объявления, которые на него ведут; конверсия = лиды назначенных объявлений / клики по ссылке. Пока ничего не назначено, сайт получает объявления, у которых большинство лидов пришло с этого сайта (авто). Привязка сохраняется в скрипте и видна всем.

Методика

Данные: при выборе дат страница забирает из API (Apps Script → amoCRM и Facebook) лиды и расход по дням за месяц(ы), в которые попадает период, и фильтрует по датам. Привязка кампаний к направлениям — из вкладки «Маппинг» инструмента, для новых кампаний — автоматически по названию (tz → ТЗ, gp/гп → ГП, kar/shym → ТЗ_Кар_Шым, kaz → ТЗ_каз, bust → Bust_plus). Квал — этап «Оффер озвучен + дедлайн», «Наработка», «Счёт выставлен», «Отказ банка», «Ответил на рассылку», продажа, либо закрыто с причиной «Дорого», «Пропала потребность», «В следующий раз», «Гасится», «Выбрали других», «Отказ рассрочки от банка». Продажа — «Предоплата / траншевая оплата» или «Успешно реализовано», выручка из поля «Бюджет». Период фильтрует лиды по дате создания сделки. Расход FB: если в выгрузке есть разбивка по дням (колонка «День»), берутся дни периода; если выгрузка за весь месяц одной строкой, расход делится пропорционально дням периода. Файлы, загруженные вручную, заменяют данные API до перезагрузки страницы.
